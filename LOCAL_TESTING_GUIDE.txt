# Smart Bill Scanner — Local Testing Guide
# No Play Store needed. Works 100% locally.

## ─── STEP 1: Start the API ────────────────────────────────────

Open PowerShell Terminal 1:

  cd C:\Users\omgan\smart-bill-scanner\api
  node src/server.js

You should see:
  ✅ API running at http://localhost:3000/api/health
  🖥️  DB Admin UI  → http://localhost:3000/admin

── TEST API WORKS ──────────────────────────────────────────────
Open in browser:
  http://localhost:3000/api/health        ← should return {"status":"OK"}
  http://localhost:3000/admin             ← DB tables UI
  http://localhost:3000/api/categories    ← 14 categories listed
  http://localhost:3000/api/ai/health-score ← AI endpoint working


## ─── STEP 2: Start the App ───────────────────────────────────

Open PowerShell Terminal 2:

  cd C:\Users\omgan\smart-bill-scanner\app
  node node_modules\expo\bin\cli.js start --web --clear --port 8081

Wait 20 seconds, then open:
  http://localhost:8081


## ─── STEP 3: Test on Physical Android Phone ─────────────────

Option A — Expo Go (easiest, no build needed):
  1. Install "Expo Go" from Play Store on your phone
  2. Make sure phone + PC are on SAME WiFi
  3. In Terminal 2, press: s  (to show QR code)
  4. Open Expo Go → Scan QR code
  5. App loads on phone in 30 seconds

Option B — Direct APK (no Play Store at all):
  1. cd C:\Users\omgan\smart-bill-scanner\app
  2. npx expo install expo-dev-client
  3. npx expo run:android
     (requires Android Studio + SDK installed)
  4. APK installs directly on connected phone via USB

Option C — Browser on Phone:
  1. Find your PC IP: ipconfig → look for IPv4 (e.g. 192.168.1.23)
  2. On phone browser, open: http://192.168.1.23:8081
  3. Full app runs in Chrome on phone

## ─── TROUBLESHOOTING ─────────────────────────────────────────

Problem: AI features not loading
  Fix: Make sure API is running on port 3000
       The app auto-detects localhost when in browser

Problem: Camera not working
  Fix: Click browser padlock → Site settings → Camera → Allow
       Then refresh the page

Problem: Gallery shows but no text extracted
  Fix: Use a clear, well-lit photo of a printed bill
       Handwritten bills have lower accuracy
       Try uploading the mock bills from /test-bills folder

Problem: Port 8081 already in use
  Fix: taskkill /F /IM node.exe  (kills all node processes)
       Then restart both servers

Problem: Physical device can't connect
  Fix: Check DEVICE_LAN_IP in app/src/config/api.js
       Set it to your PC's IP from: ipconfig
       Phone and PC must be on same WiFi network
